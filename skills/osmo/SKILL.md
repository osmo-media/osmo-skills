---
name: osmo
description: Create, edit, preview, and render animations with Osmo. Use when the user requests Osmo or work on an Osmo animation project.
---

Use the installed Osmo CLI for this task. Keep using the project's existing CLI
invocation; otherwise use `osmo`.

- Run `osmo --help` to discover the installed version's commands. Use the same
  invocation prefix for every command below.
- In an existing project, read its `AGENTS.md` and the relevant installed
  `@osmo/scene` declarations before editing.
- For a new project, run `osmo init <folder>`, then read the generated `AGENTS.md`.
- Follow those instructions to edit scenes, use resources, validate, preview,
  and render the requested result. Detailed guidance belongs to the installed CLI.
- If the CLI is unavailable, explain that private CLI access is required and
  refer to the [installation instructions](https://github.com/osmo-media/osmo-skills#install-the-cli).
